# Zeline Zenith 🔥

**Sovereign Autonomous Agent Framework** — 82 skills, 60 tools, production-grade.

## Quick Start

```bash
pip install zeline-zenith

# Or with crypto/web3 support:
pip install zeline-zenith[crypto]
```

## CLI Commands

```bash
zeline-zenith scan                    # Run revenue engine scan
zeline-zenith auth <challenge> <sig> # Verify team auth signature
zeline-zenith bridge status          # ZelineBridge cross-chain status
zeline-zenith treasury [daily|weekly|monthly]  # P&L cost ledger report
zeline-zenith deploy-gateway         # Gateway manager deployment
zeline-zenith dashboard [--serve PORT]  # Live web dashboard
zeline-zenith eval <label>           # Agentic eval suite
zeline-zenith watchdog tick          # Self-healing watchdog check
zeline-zenith reflection cycle       # Self-improvement reflection
zeline-zenith triage                 # Inbox notification triage
zeline-zenith integrity verify       # Skill integrity checks
zeline-zenith model list|add|remove  # LLM model registry
zeline-zenith upgrade <zip> [--dry-run]  # Version upgrade
zeline-zenith version                # Version + tool summary
```

## Architecture

- **82 Skills** — On-demand modules for crypto, DevOps, content, automation, CTF, and more
- **60 Tools** — Core engine: revenue, cost ledger, reflection, eval, watchdog, swarm, model registry
- **Zeline Runtime** — Multi-chain Web3 ops: swap, bridge, DeFi, NFT, MEV
- **Zero Required Deps** — Core runs on Python stdlib; optional extras for crypto/web3
