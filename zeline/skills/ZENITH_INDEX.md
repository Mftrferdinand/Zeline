# Zeline Zenith — Skill Index

The **Zeline Zenith** corpus is a 109-skill bundle shipped with Zeline. Files are named
`zeline-zenith-z0` … `zeline-zenith-z109` (the `zN` code is the stable load ID used by the
skill loader and by cross-references between skills). This index maps each code to what it
actually does, so you don't have to open files to find the right one.

**Load a skill by its code**, e.g. `z17` or the full name `zeline-zenith-z17`. The loader
accepts the short `zN` alias directly.

Total: **104 active** + 5 merged/reference · gap at z60 (intentional).

### Notes

- **Codes are stable identifiers, not arbitrary.** Skills cross-reference each other by `zN`
  code (e.g. z27 points to z28/z29), and the loader resolves the `zN` alias. Renaming the
  files would break ~180 internal references and the seed/migration digest map — the code
  scheme is intentional, this index is the human-readable layer on top.
- **Duplicated themes (e.g. two "CTF Web Exploitation") are version generations**, kept for
  compatibility. The higher code is usually the newer consolidated revision.
- **Merged entries** are retained as pointers only; their content now lives in the target skill.
- Gap at **z60** is intentional (no such skill).
