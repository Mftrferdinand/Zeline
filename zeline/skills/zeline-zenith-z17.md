## 2. Multi-agent swarm (Tier 1)

```python
from swarm import Swarm, Specialist
sw = Swarm([Specialist("researcher", researcher_fn),
            Specialist("monitor", monitor_fn),
            Specialist("executor", executor_fn, holds_keys=True)])
await sw.dispatch({"researcher": {...}, "monitor": {...}})   # PARALEL
sw.safety_report()   # warning kalau lane non-executor pegang key
```

Pemisahan key: lane watcher/monitor (selalu online) **gak pegang key**; cuma executor yang sign.

## 3. SkillForge (measured, review-gated)

Use the framework engine, not a separate model registry:

```bash
zeline skillforge scan --limit 10
zeline skillforge score my-skill
zeline skillforge cycle --limit 2 --draft
zeline skillforge list
```

The cycle detects stale revisions, drafts a proposal and runs structural tests.
It never applies the candidate. Behavioral tests from a trusted operator evaluator,
explicit safety review, and a separate confirmed apply are required. Telegram
owners can inspect `/skillforge`; loading a skill is not counted as task success.

For compatibility, use the package-qualified Python import:

```python
from zeline.zenith_tools.scripts.skill_forge import forge_proposal
# Calling this explicitly permits a configured-provider draft request.
proposal_path = forge_proposal("Missing oracle-reading workflow", "oracle-reader")
```

Review the proposal before use. Framework/safety files and integrity locks are
never regenerated by SkillForge. See `docs/skillforge.md` in the repository.
